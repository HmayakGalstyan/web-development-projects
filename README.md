# HTML, CSS & JavaScript Practice Projects

A collection of educational web-development assignments completed while studying HTML, CSS, and JavaScript.

## Projects

| Project | Main technologies | Description |
| --- | --- | --- |
| [Indicorp landing page](./indicorp-landing-page/) | HTML, CSS | Multi-section business landing-page layout and responsive CSS practice. |
| [Organick landing page](./organick-landing-page/) | HTML, CSS | Multi-section organic-product landing-page layout and responsive CSS practice. |
| [JavaScript quiz](./javascript-quiz/) | HTML, CSS, JavaScript | Interactive multiple-choice questions with answer feedback and a score display. |
| [JavaScript image slider](./javascript-image-slider/) | HTML, CSS, JavaScript | Image navigation with previous/next buttons and clickable thumbnails. |

## Usage

Open any project's `index.html` in a browser. No package installation or build step is required.

## Notes

- These are **learning exercises**, not production-ready software or original commercial site designs.
- The HTML, CSS, and JavaScript source code was retained as submitted. Bundled font files were excluded; typography may differ from the original. Use fonts you are licensed to redistribute when publishing.
- Some JavaScript exercises need further testing and bug fixes. In the quiz, repeated clicks can affect the score; the slider's JavaScript image paths may need adjustment when opened from its `index.html`.
- Before publishing, check that images, fonts, icons, and copied design assets may legally be redistributed.
